# Security Policy

We take the security of 3pigeons code seriously. If you find a vulnerability, please tell us privately so we can fix it before it is disclosed.

## Reporting a vulnerability

- Email **[security@3pigeons.xyz](mailto:security@3pigeons.xyz)**, or
- Use GitHub's **"Report a vulnerability"** button on the affected repository's **Security** tab.

Please do **not** open a public issue for security problems.

Helpful details to include:

- The affected repository, contract or component, and version or commit
- Steps to reproduce, or a proof of concept
- The potential impact

## What to expect

We will acknowledge your report, keep you updated while we investigate, and credit you when the fix is published if you would like.

Please give us reasonable time to fix the issue before disclosing it publicly, and do not access or modify other people's funds or data while testing.
